# Products screens

## Why
Admins and managers need to add and edit catalogue products. See the backend note of the same date.

## What changes
- `lib/api/products.ts` (new): typed client for `/products`.
- `app/dashboard/products/page.tsx` (new): searchable list with brand and category filters, paging, and the loading, empty and error states.
- `app/dashboard/products/new` and `[id]` (new): add and edit through `components/products/ProductForm.tsx`, with sections for basic info, model, features, pricing, specs and media. Slug follows the name until edited, discount and savings update live, new brands, categories and materials can be added in place.
- `DashboardSidebar.tsx`: "Products" entry for admin and manager.

## Out of scope
Image upload (a URL is pasted), mobile. Filters are held in component state, not the URL.

## Verification
`tsc` and `eslint` are clean for the new files. Not yet clicked through in a browser.
